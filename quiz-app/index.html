🍍 NanasBelajar

Sistem quiz sederhana untuk belajar dan berlatih. Guru dapat memasukkan soal, siswa dapat mengerjakan quiz, dan hasil langsung tersimpan.

▶ Mulai Quiz ✏ Input Soal 📋 Daftar Nilai

Cara Penggunaan

1. Input Soal

Guru mengetik soal dalam format teks sederhana. Sistem akan memecah teks menjadi soal secara otomatis.

2. Preview & Simpan

Periksa hasil parsing soal sebelum disimpan. Jika ada kesalahan, bisa diedit kembali.

3. Kerjakan Quiz

Siswa memasukkan nama lalu mengerjakan semua soal dengan memilih jawaban yang tersedia.

4. Lihat Nilai

Setelah selesai, nilai langsung dihitung dan ditampilkan beserta review jawaban soal per soal.

Informasi Penyimpanan

Data soal dan hasil quiz disimpan di localStorage browser ini. Data akan tetap ada meskipun browser ditutup, tetapi akan hilang jika Anda menghapus data browser atau membuka di browser/perangkat yang berbeda.
